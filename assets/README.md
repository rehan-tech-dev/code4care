# Code4Care Assets Directory

This folder is reserved for static assets such as:
- Vector icons
- Future 3D models or human body SVG anatomy layers
- Audio chimes for meditation & breathing pacers
- Brand imagery

All current icons are rendered as lightweight, scalable inline SVGs within `js/tools-data.js` and `index.html` to eliminate external HTTP requests and ensure instant, offline-first performance when double-clicking HTML files directly.
